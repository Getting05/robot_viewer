# Link 原点与三维测距

顶部工具栏新增 **Link 原点** 和 **测距**。

两个面板与原查看器共用毛玻璃浮动面板、按钮、数值输入框和深浅色主题。拖动标题栏可移动面板，拖动边缘可调整大小，右上角支持最大化 / 还原与关闭。

- **Link 原点**：默认关闭；开启后显示与质心相同几何形状和大小的橙白相间球体，悬停显示名称，点击显示直接父关节、父 link、世界位置及相对父 link 的 XYZ / RPY（XYZ 欧拉角，弧度）。根 link 以世界为参考。
- **任意两点**：进入测距后依次点选模型表面或地面。也可直接填写 A、B 的 XYZ 后点击“应用坐标”，无需先点模型。点击 A/B 按钮或已有端点可选择端点，再用三轴手柄拖动。
- **结果**：直线距离始终显示，另显示带符号的 ΔX / ΔY / ΔZ。尺寸线可选择全部轴或单个轴；单位支持 mm / m。
- **坐标系**：默认查看器世界坐标（Y 向上，与机器人文件的 Z 向上可能不同）。A 有所属 link 时可选“起点 Link”。切换保持端点世界位置不变；输入框和分量统一使用所选坐标系。
- **绑定**：表面点和特殊点随所属模型运动。输入或拖动后成为自由点；世界模式固定于世界，局部模式跟随参考 link。修改 A 的坐标不会丢失已选参考 link。
- **吸附**：总开关和分类开关控制 link 原点、关节原点、link 质心和地面投影；默认开启。12 CSS 像素内显示预览并吸附，可吸附被几何体遮挡的基准点。投影含上述特殊点以及 A 到实际地面平面的垂足，不需要先打开普通质心显示。没有有效惯性数据的 link 不生成质心点。
- **轴向拖动**：只沿选定轴移动；吸附候选必须落在该轴上（模型尺度 × 1e-6 的容差）。精确坐标输入不会吸附。
- **操作**：测距时禁止拖动关节，但可用原有关节面板调节姿态。拖动画布仍可控制相机；操作手柄时临时锁定相机。Esc 退出测距（拖动中先复位本次拖动）；重新测量和清除均会清除两端点。
- **模型树**：保留 Ctrl 点选两个 link/joint 的测距方式；选择 ground 时连接另一端点的地面垂足。

主查看器支持 URDF / Xacro / MJCF 的姿态调节和动画。USD 独立查看器与 MuJoCo 独立物理场景暂不支持；打开测距面板会显示原因。模型更换或卸载后清空端点。

## 视角立方体

画布右上区域提供随相机同步旋转的视角立方体，沿用原查看器的毛玻璃样式与深浅色主题。点击“前 / 后 / 左 / 右 / 顶 / 底”切换对应方向，点击“等轴测”回到斜视角；也可拖动立方体旋转观察。切换保留当前观察中心和相机距离，不修改模型姿态。

面上的轴标签采用查看器世界坐标：前后为 ±Z，左右为 ±X，顶底为 ±Y。与模型文件的原始坐标可能不同。该控件用于主查看器，USD 独立查看器中隐藏。

## 验证

```sh
pnpm test
pnpm build
```

`tests/measurement/math.test.js` 覆盖 13 m 空间距离、坐标变换、移动绑定、地面投影、单位和输入校验、轴约束及有效质心过滤。

`tests/measurement/fixtures/` 提供无需外部网格的 URDF / MJCF 验证模型。

另有可选浏览器回归检查，不引入应用运行时依赖。环境需安装 Playwright 及 Chromium，启动 `pnpm dev` 后运行：

```sh
node tests/measurement/browser-check.cjs
```

可通过 `PLAYWRIGHT_MODULE` 指定已有 Playwright 模块位置，`BROWSER_EXECUTABLE` 指定 Chromium/Edge 可执行文件，`VIEWER_URL` 指定开发服务地址（默认 http://127.0.0.1:3000）。该检查使用两个模型验证坐标输入、绑定跟随、坐标系切换、吸附、实际鼠标取点/轴向拖动/相机操作和模型清理，并将截图保存到系统临时目录。

视角立方体及球体标记的浏览器回归检查：`node tests/measurement/view-cube-browser.cjs`，使用上面相同的 Playwright 环境参数。
